# MSS Knowledge v0.1.0 verification record

This document records evidence for the first verifiable release. A pushed commit is not treated as a verified release until the corresponding checks have completed successfully.

## Target vertical slice

The v0.1.0 target is:

1. start PostgreSQL, Redis 8 Query Engine, Gateway, and Worker;
2. authenticate with a development bearer token;
3. expose authorization-filtered knowledge-base catalog data;
4. search active, authorized chunk projections through REST;
5. fetch an active, authorized chunk through REST;
6. expose the same read-only `search`, `fetch`, and `list_knowledge_bases` operations through MCP Streamable HTTP;
7. import at least one TXT or Markdown document through the supported ingestion path;
8. verify tenant isolation, active-version filtering, citations, migration rollback, and Redis rebuild behavior.

## Implemented checkpoint

Commit `2810cf3cc332346c22a72cc3b5d1a27eea012359` implements the authenticated Redis REST and MCP read path, including:

- static bearer authentication for development and test environments only;
- PostgreSQL authorization-filtered knowledge-base catalog access;
- Redis Query Engine chunk indexing, hybrid lexical/vector retrieval, exact fetch, and RRF fusion;
- deterministic local embeddings for repeatable verification, not production semantic quality;
- REST endpoints for catalog, search, and fetch;
- read-only MCP tools for catalog, search, and fetch;
- active-version and final ACL revalidation.
